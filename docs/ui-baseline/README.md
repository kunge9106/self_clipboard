# UI 基线截图（期 0 产物）

改造前先留一份「原来长什么样」，否则改造完无法证明**只是变清楚、没有变样**。

## 为什么要人来拍

我（AI）拿不到窗口像素：截图要经过 WebView2 + 自绘材质，只能由能看到窗口的人操作。
所以这一步是**唯一必须你做的一步**，其余（审计脚本、报告）都已经自动生成。

## 怎么拍（3 步，约 5 分钟）

1. 用**已安装的 2.6.10 正式版**（不是 `npm run tauri dev` —— dev 版材质与窗口行为一致，
   但基线应对齐用户实际使用的那个包）。
2. 主题切**浅色**，材质保持默认（能看到模糊的那档，不要落到 `solid` 兜底）。
3. `Win + Shift + S` 截图 → 存到本目录，命名为 `NN-说明.png`（NN = 01–10，例如 `01-卡片无边界.png`）。

只截**问题区域 + 一点上下文**，不用全屏。看不清的地方比整屏更有价值。

## 拍哪里（10 个候选，按怀疑程度排序）

下面是我从代码里读出来的可疑点。**同意就拍，不同意就跳过**，不需要凑满 10 张；
有别的看不清的地方直接补在 11、12…，名字里写清楚就行。

| # | 位置 | 为什么怀疑 |
|---|---|---|
| 01 | 列表里卡片之间 | `--line` 实测 1.23:1，低于「可辨底线 1.5」 |
| 02 | 卡片描边 | 浅色下 `--stroke` 合成后**是纯白**（1.00:1），等于没有边 |
| 03 | 卡片悬浮（鼠标停在卡上） | `--card-hover` 与 `--card-bg` 在 `solid` 档都是白，看不出变化 |
| 04 | 搜索框边框 | 同样用 `--stroke`，浅色下隐形 |
| 05 | 状态栏分隔线 | 用 `--stroke`，浅色下隐形 |
| 06 | 状态栏右侧两个图标 | 纯图标无文字、颜色是 `--text-dim`，很容易点错 |
| 07 | 设置页开关（原生 checkbox） | 16px 原生控件，浅色下轨道对比低 |
| 08 | 右侧滚动条 | 4 处硬编码 rgba，浅色下很淡 |
| 09 | 右键菜单 | 底色 `--solid-bg` + `--stroke` 边，浅色下边框不见 |
| 10 | 键盘 Tab 焦点 | `input:focus` 被 `outline:none` 干掉后没补环，**输入框聚焦可能完全看不见** |
