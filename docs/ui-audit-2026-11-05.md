## 3. 值级对比度（WCAG）

按「材质 → 卡片 → 文字/描边」逐层合成后计算，不是比较字面颜色。
壁纸取最坏情况（纯白 / 纯黑）—— 浅色主题在深色壁纸上会不会糊，就看这张表。

门槛说明：文字按 WCAG AA；**描边与分隔线用自定的「可辨底线 1.5」**，不套 WCAG 的 3:1 —— 那条针对的是「识别控件所必需的边界」，把它套到卡片描边上会得出「边要加深到黑 .42」这种毁观感的结论。
