## 3b. 面层级差（「两块面分不分得出来」）

对比度回答「文字能不能读」，**层级差回答「哪块是哪块」**。
用户反馈的「底色与背景太相同」属于后者 —— 只盯对比度会得出「全部达标」的错误结论。
门槛 1.06 ≈ 亮度差 3%，是 Linear / Notion / Fluent 共用的「whisper-quiet」档位：
再低两块面就真的并成一片，再高就开始显得厚重。
