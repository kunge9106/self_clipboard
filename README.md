# 轻贴 — 本地剪贴板管理工具

轻贴（self_clipboard）是一款 Windows 桌面剪贴板历史管理工具，采用 VisionOS 风格毛玻璃界面。

## 功能

- **自动监听剪贴板**：实时记录复制的文本和图片
- **历史记录管理**：浏览、搜索、复制历史记录
- **图片缓存**：自动保存剪贴板图片，支持查看
- **搜索过滤**：快速筛选历史内容
- **系统托盘**：后台常驻，快捷键唤醒
- **深色模式**：自动跟随 Windows 主题切换
- **开机自启**：可选开机自动启动

## 技术栈

| 技术 | 用途 |
|------|------|
| Electron 42 | 桌面框架 |
| HTML/CSS/JS | 渲染进程 UI |
| VisionOS 风格 | 毛玻璃设计 |

## 开发

```bash
# 安装依赖
npm install

# 运行
npx electron .
```
