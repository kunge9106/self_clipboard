## 简介

轻贴是 Windows 桌面剪贴板历史管理器，常驻托盘，记录剪贴板中的文本、图片与文件；需要时在窗口中检索并复制，内容写回剪贴板。

应用为单机工具，无账号、无云端。除检查更新外不产生网络请求：启动时静默查询一次 GitHub 公开版本信息，其余仅在手动触发，只读取版本数据，不上传本机内容。历史数据存放在本机缓存目录，默认 `%APPDATA%\com.kunge.selfclipboard\clipboard`，可自定义。

安装包 1.4 MB；基于 Electron 的 v1 为 89 MB。启动后进程组占用约 120 MB，其中主进程约 40 MB，其余为系统 WebView2 的多进程开销。

## 界面

![轻贴主界面](assets/readme/preview.svg)

窗口左侧为分类导航（底部有深浅色快捷切换与设置入口），右侧为搜索框与历史列表，底部显示条数与版本。条目右键菜单提供复制、查看、编辑、置顶、收藏、批量删除与删除。

## 功能

### 采集

- 文本、图片、文件。文件指资源管理器中复制的文件。
- 微信、QQ 复制图片时写入剪贴板的是临时图片文件而非位图，轻贴解码后按图片条目记录。
- 监听基于剪贴板事件，非轮询，空闲时 CPU 占用接近零。
- 内容全部落盘，内存仅保留索引元数据。

### 浏览

- 卡片显示 2 行预览，长内容在末尾加省略号。
- **悬浮预览**：鼠标停留 1 秒弹出浮层 —— 文本显示前 4 行、文件列出前 3 个文件名。卡片上本来就显示全的内容不会再弹，只在「看不全」时帮你确认是不是这条。
- 右键「查看」打开弹窗看全文与完整路径，长文本可在这里全选或复制。
- **右键「编辑」**：改的是副本，保存后写回剪贴板并**另记一条带「已编辑」徽章**的条目，原条目始终保留不动。

### 查找

- 实时搜索，命中范围为文本正文、文件名与类型名；搜索「图片」或 `image` 均返回图片条目。
- 五个分类：历史、文本、图片、文件、收藏，对应视图名 `history`、`text`、`images`、`files`、`favorites`。
- 置顶按分类独立：在文本分类置顶不改变条目在历史分类中的位置。
- 卡片徽章标识类型、已置顶、已收藏、已编辑、已失效，时间在右侧对齐成一列；类型徽章按类型分色（文本黄绿、图片紫、文件青绿），小字号下也分得开。

### 整理

- 收藏与置顶条目在清理历史时自动豁免。
- 缓存目录可迁移，并实时显示占用大小。迁移到空目录时直接使用；迁移到非空目录时在其下创建缓存子文件夹，不改动原有内容。
- 文件条目失效检测：原文件被移动或删除后标记为「已失效」，点击时提示跳过的条目数量；设置 →「记录与缓存」可**一键清空已失效条目**（先检测再确认，不误删还活着的）。
- **保留天数默认 3 天**，到期自动清理（这是最容易被误会成「记录丢了」的一条）；设为 0 表示永久保留，设置页显示「永久保存」。
- 危险操作二次确认：「清空全部历史」列出条数并提示含置顶与收藏且不可撤销；工具栏垃圾桶仅在范围内含置顶或收藏时弹出，可勾选是否一并清理。

### 外观

- 外观主题三选一：浅色、深色、系统（默认跟随系统）。侧栏设置按钮上方另有快捷切换按钮，点一下在浅色与深色之间来回切；手动切过即固定在那一档，想要恢复跟随就到设置里改回「系统」。
- 深色是真正的黑：深色模式下材质浓度很高，桌面壁纸不会把它冲成灰。
- 材质浓度滑块调节窗口通透度，直角与圆角两个模式各自记录一档浓度。
- 圆角模式开关在圆角通透与直角毛玻璃之间切换，见「材质与圆角」。
- 「不跟随系统缩放」（默认开启）：Windows 调整缩放比例后界面不再跟着放大缩小，可避免高缩放下布局错位；关掉即回到系统本身的缩放行为。

### 设置

- 按通用、外观、记录与缓存、关于四个标签分页。
- 覆盖安装时欢迎页显示旧版本与新版本，并提示先退出运行中的轻贴。

### 首次运行

- **7 步功能导览**：讲完自动记录、左键与右键各能做什么、悬浮预览、搜索分类、文件条目、设置里最容易踩的坑、隐私与退出。看完或跳过都不再出现，设置 → 通用 →「重新查看功能引导」可随时回看。老用户升级不会被弹。
- 全新安装后的第一次启动询问是否开机自动启动，选择「暂不开启」后仍显示后续开启的位置。
- 第一次点击关闭按钮时询问后台运行或直接退出。
- 两项均只询问一次，之后可在设置中修改。

### 关于页

- 显示运行环境自检结果：系统版本与 build、实际生效的材质档位、圆角模式、开机自启、当前内存占用、缓存目录。
- 提供项目主页与问题反馈入口。

### 更新

- 启动时静默自检一次，仅在存在新版本时提示：侧栏「设置」与「关于」标签出现红点，窗口顶部弹出一次横幅。检查失败或无新版本时不提示。
- 关于页的「检查更新」在存在新版本时变为「下载最新版」，按钮底色从左向右填充并显示百分比，下载完成后以管理员权限启动安装包并退出自身。
- 正式版只查询稳定通道，不显示 beta；beta 版同时接收 beta 与正式版。
- 更新日志随包内置，关于页显示本机所运行版本的说明，内容取自仓库 [CHANGELOG.md](./CHANGELOG.md)。

### 稳定与排查

- 单实例：同一版本只允许运行一个实例，再次启动时唤回已有窗口并弹出应用内说明。测试版与正式版锁名不同，可同时运行。
- 全局日志写入缓存目录 `log/`，文件名为 `Clipboard.log`；超过 64 MB 时保留尾部 32 MB。程序崩溃时另存 `Clipboard-崩溃_<时间戳>.log`。日志只记事件与元数据，**不记剪贴板原文**。

### 后台

- 托盘图标常驻，右键菜单与主窗口使用同一套样式与材质。
- 开机自启。
- 关闭窗口时后台运行，隐藏至托盘。
- 退出时可清理缓存，可选是否连同置顶与收藏一并清理。

## 下载与安装

从 [Releases](https://github.com/kunge9106/self_clipboard/releases/latest) 下载最新的 `轻贴_<版本>_x64-setup.exe` 并安装。

- 安装器为中文界面。
- 安装位置为 Program Files，双击后请求管理员权限并弹出一次 UAC 确认。
- 系统要求 Windows 10 1809 或更高版本。
- 升级前请先退出运行中的轻贴（托盘右键 → 退出）。
- 安装包使用 WebView2 在线引导模式。Win11 与较新的 Win10 已内置 WebView2；系统未安装时，安装过程中联网下载引导包。

## 基本操作

1. 从开始菜单或托盘打开轻贴，窗口显示已记录的条目，首次运行列表为空。
2. 复制文本或图片后，条目出现在窗口中。
3. 条目右键菜单提供复制、查看、编辑、置顶、收藏、删除。
4. 在顶部搜索框输入关键词进行检索。
5. 记录资源管理器复制的文件需开启 设置 → 记录与缓存 → 文件复制，该开关默认关闭。

文件条目记录的是路径引用而非文件副本，原文件被移动或改名后无法复制回剪贴板。该功能涉及本机磁盘路径，故默认关闭。

## 材质与圆角

窗口材质按系统版本自动分档，启动时在终端打印实际生效的档位。

| 系统 | build | 材质 | 圆角上限 |
|---|---|---|---|
| Win11 22H2+ | ≥ 22621 | `DWMWA_SYSTEMBACKDROP_TYPE` 系统级 acrylic | 12px，系统圆角 |
| Win11 21H2 | 22000 | Mica | 12px，系统圆角 |
| Win10 1809 – 22H2 | 17763 – 19045 | `SetWindowCompositionAttribute` 真 acrylic | 20px |
| 更低版本或调用失败 | — | 不透明兜底 | 12px |

Win10 上圆角与系统模糊无法同时满足：acrylic 始终铺满窗口矩形，`SetWindowRgn` 对其无效，圆角越大，四角露出的方形模糊越多。轻贴提供两种处理。

- 开启圆角模式：关闭系统模糊，窗口四角为真透明，背景壁纸不再模糊。
- 直角模式为默认：保留系统毛玻璃，窗口为直角，矩形与 acrylic 完全吻合，无残留。

## 数据与存储

默认缓存目录为 `%APPDATA%\com.kunge.selfclipboard\clipboard\`，可在设置中改为任意路径。

```
clipboard/
├─ index.json        索引：id / 类型 / 预览 / 时间 / 置顶与收藏 / 大小（DPAPI 加密）
├─ data/<id>.txt     文本正文（DPAPI 加密）
├─ images/<id>.bmp   图片
│  └─ thumbs/        缩略图，捕获后立即后台生成
├─ files/<id>.txt    文件清单，每行一个完整路径（DPAPI 加密）
└─ log/              日志，含 Clipboard.log 与崩溃快照
```

内存仅保留索引元数据，正文、图片与文件清单按需从磁盘读取，列表滚出视野后释放。删除条目、清理缓存与退出清理均同步删除对应的落盘文件。

文本正文、文件路径清单与索引文件均用 Windows DPAPI 加密后落盘，密钥由系统按当前 Windows 账户保管，无需设置口令。**注意**：换 Windows 账户或换机器后，旧数据无法解密（这是 DPAPI 的固有语义）。

## 构建与开发

环境要求：

- Rust stable，MSVC 工具链
- Node.js 18+
- WebView2 Runtime

本项目在 Windows 上使用系统 Node 构建前端；托管环境自带的 Node 调用 esbuild 时可能因 `spawnSync` 被拦截而报 `EBUSY`。

```bash
# 安装前端依赖
npm install

# 开发运行，自动启动 Vite 与 Tauri 窗口
npm run tauri:dev

# 构建安装包，产物在 src-tauri/target/release/bundle/nsis/
npm run tauri:build
```

技术栈：

| 技术 | 用途 |
|---|---|
| Tauri 2 | 桌面框架，Rust 与系统 WebView2 |
| Rust | 剪贴板监听、窗口材质、存储、托盘 |
| 原生 HTML / CSS / JS | 前端，无框架 |
| Vite | 前端开发服务器与打包 |

## 已知限制

- 无全局快捷键，唤出依赖打开窗口或托盘双击。
- 无虚拟滚动；列表使用渐进渲染，每批 60 条，历史量极大时滚动仍会累积节点。
- 内存无法降至几十 MB 量级，窗口由系统 WebView2 承载，多进程模型存在固定开销。
- 文件条目为路径引用而非快照，原文件变动后复制出的内容随之变化，删除后条目失效。
- 仅支持 Windows，材质、托盘与自启均基于 Win32 实现。
- Win11 的 DWM 为顶层窗口提供系统圆角，圆角模式开关改变的是背景模糊与材质观感，不改变边角形状；圆角半径跟随系统原生值，`DWMWA_WINDOW_CORNER_PREFERENCE` 只提供定性选项。
- Win10 上低浓度材质在纯色背景上的观感弱于 Win11。

## 常见问题

**托盘图标在什么位置？**
程序启动后常驻托盘。右键弹出菜单，含显示轻贴与退出；双击唤回窗口。

**内存占用为何高于几十 MB？**
窗口由系统 WebView2 渲染，多进程模型存在基础开销。在保留真毛玻璃与图片缩略图的前提下已尽量压缩。

**点击文件条目提示找不到文件？**
文件条目保存路径引用而非副本。原文件被移动、改名或删除后条目失效，界面标记为「已失效」，点击时提示跳过的条目数量。

**能否在 Win7 上运行？**
不能，最低要求 Windows 10 1809。

**安装时报「无法打开要写入的文件」？**
v2.1.0 及更早的安装器不申请管理员权限，安装到 Program Files 时报此错误，需以管理员身份运行；v2.1.5 起安装器自动请求权限。

**Win11 上切换圆角模式，边角没有变化？**
Win11 的 DWM 为顶层窗口提供系统圆角，开关状态不影响边角形状；该开关改变的是背景模糊与材质观感，设置页已注明。圆角半径跟随系统原生值，`DWMWA_WINDOW_CORNER_PREFERENCE` 只提供定性选项，无法指定像素值。

**双击图标后没有反应？**
轻贴为单实例程序。同一版本已在运行时，第二次启动不创建新窗口，而是唤回已有窗口并弹出说明。测试版与正式版锁名不同，可同时运行。

**崩溃或行为异常如何反馈？**
从缓存目录 `log/` 取 `Clipboard.log`；若程序崩溃过，另存 `Clipboard-崩溃_<时间戳>.log`。将文件提交到 [Issues](https://github.com/kunge9106/self_clipboard/issues)。

**如何升级到新版本？**
启动时自动检查一次，存在新版本时侧栏「设置」与「关于」显示红点。在关于页点击「下载最新版」，下载完成后启动安装包覆盖安装，设置与历史保留。也可从 [Releases](https://github.com/kunge9106/self_clipboard/releases/latest) 下载。

**beta 版与正式版的区别？**
正式版只查询稳定通道，不显示 beta；beta 版同时接收 beta 与正式版本。两者单实例锁名不同，可同时安装。

**关于页的检查更新如何连接网络？**
调用系统自带 `curl.exe` 访问 GitHub，按上次成功记录、环境变量、系统代理、直连的顺序逐个尝试，全部失败后提示检查网络。首次检查可能耗时数秒。
