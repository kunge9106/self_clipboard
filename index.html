复制过的，都在这儿

轻贴常驻后台，文本、图片、文件都会自动记下来：

文本 文字、代码、链接
图片 截图、网页图
文件 默认关闭
代码 function hello() { return 1 } 刚刚

链接、代码、Markdown 会被自动认出来并标在卡片上。记下来就长这样， 点一下即可复制回剪贴板。关掉窗口也照记。

左键复制，右键有更多

  • 左键点卡片 —— 立刻复制回剪贴板，去别处粘贴
  • 右键「复制」 —— 同样的效果，不想误点时用
  • 右键「查看」 —— 长文本、长路径列表看全文
  • 右键「删除」/「批量删除」 —— 删单条，或进入选中模式勾一批

批量删除：右键进入后左键点条目即选中，Esc 或切分类退出。

复制带着格式一起存

从网页、Word 复制来的内容，粗体、颜色、表格、超链接都保留。

  • 默认按原格式粘贴 —— 左键点卡片或右键「复制」都是这个结果
  • 只要纯文字 —— 右键「复制为纯文本」。这一项只在带格式的条目上出现， 普通文本没有
  • 粘到不支持富文本的地方 —— 记事本这类目标会自动收到纯文本，不用先转换

图片和文件条目没有这一项：它们本身就是二进制或路径。

编辑是改副本

右键「编辑」可以改内容再复制出去，改动不会覆盖原条目。

  • 保存后另起一条 —— 新记录带「已编辑」徽章，方便和原文区分
  • 原条目原样保留 —— 改坏了直接再用原文，不用重新复制

历史始终反映当初复制了什么，事后改动单独记一条。

分类、搜索、置顶与收藏

  • 分类 —— 左侧可只看文本、图片或文件
  • 搜索 —— 顶部搜索框按内容、文件名、类型搜，输入「图片」或 image 都行
  • 置顶 —— 让某条浮到最上面。默认「按分类独立」（在文本里置顶不影响历史）， 可在 设置 → 常规 → 置顶 → 「置顶互通」改成全分类同步
  • 收藏 —— 标记常用内容，左侧「收藏」一栏集中查看

置顶和收藏的条目在到期清理时会被跳过，不会自动清掉。

鼠标停 1 秒，看更多

  • 图片 —— 弹出大图
  • 文本 —— 比卡片多显示几行（卡片只有 2 行）
  • 文件 —— 列出前几个文件名，更多折叠成「另有 N 个」

卡片已经显示全的内容不会弹浮层。全文和完整路径用右键「查看」。

文件功能默认关闭

  • 开关 —— 设置 → 数据 → 记录 → 「文件复制」。复制文件没反应就是这条没开
  • 存的是路径，不是副本 —— 原文件被移动、改名或删除后，卡片会压暗并标「已失效」
  • 可以批量清掉 —— 设置 → 数据 → 危险操作 →「清空已失效」，一键清理， 仍存在的条目不会误删
  • 保留天数 —— 同页「记录」，默认 3 天，改成 0 才是永久保存

复制的文件里若有失效的，粘贴时会自动跳过并提示跳过了几个。

不切窗口，直接取

在任何程序里按 Ctrl + Alt + V 唤出快捷面板，光标旁列出最近的内容。

  • 选择 —— ↑ ↓ 上下移动，也可以鼠标点
  • 粘贴 —— 点击条目或按回车，内容直接粘进唤出前的输入框；焦点不在输入框时只复制
  • 收起 —— 点别处就收起；Esc（可改）或再按一次快捷键也可以

想「先去别的窗口看一眼再回来选」，到 设置 → 常规 → 快捷操作 打开 「失焦不收起」。

截图也进轻贴

按 Alt + Q 截图，截完的图直接进「图片」分类。

  • 默认 —— 用 Windows 自带截图工具，箭头、文字、马赛克都能画
  • 换成内置 —— 设置 → 常规 → 快捷操作 → 「截图方式」选「内置」：屏幕先定格再框选， 支持窗口识取与尺寸标注；右键取消，且不动剪贴板里原有的内容

键位随你改

两个快捷键都在 设置 → 常规 → 快捷操作，谁都能改、也都能关。

  • 改键 —— 点一下按钮开始录制，按下想要的组合即可
  • 冲突 —— 被别的软件占用会明确提示，不会静默失效
  • 关掉 —— 每个热键单独开关；不需要截图就只留面板

外观：主题、浓度、圆角

  • 主题 —— 浅色 / 深色 / 跟随系统。设置 → 外观 → 主题， 侧栏底部也有一个快捷切换按钮
  • 材质浓度 —— 设置 → 外观 → 窗口。直角与圆角各记一档，来回切模式不互相覆盖
  • 圆角模式 —— 四角真透明，边缘由界面自己画、带抗锯齿； 代价是没有系统背景模糊，所以浓度需要调高一些

直角模式保留壁纸模糊，圆角模式四角更干净。两种模式都在「外观 → 窗口」里切。

内容只在本机

  • 加密 —— 正文、文件路径、索引全部用 Windows 账户级密钥加密， 换账户或换机器都读不出来
  • 退出 —— 设置 → 常规 → 启动 里选了「关闭时后台运行」，点右上角 × 只收进托盘； 没选则直接退出
  • 图标不见了？ —— Windows 会把新图标折叠进任务栏的 ^ 里，可以拖出来固定

更新在启动时自动检查，有新版本会在窗口内弹一条横幅；完整更新日志在「关于」。 设置其余项目按字面意思调即可，随时可以在 常规 → 帮助 里重看这份引导。
